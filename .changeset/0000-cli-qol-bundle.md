CLI quality-of-life bundle: new `airs completion <bash|zsh|fish>` command generating shell completion scripts with install snippets; global `--quiet` flag suppressing status and decorative output while keeping data, results, and errors; usage examples in `--help` for the most-used commands; interactive Y/N confirmation prompts on destructive operations (profiles/topics/targets delete, topics revert, profiles cleanup) with `--force` bypass and exit-2 refusal in non-interactive mode; and `ls`/`rm` aliases on every `list`/`delete` subcommand.
