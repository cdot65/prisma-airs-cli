aliases and optional examples. Every identifier, observation and assessment is
synthetic; these files contain no user tenant data and do not establish live API
qualification. The HTML, evidence and blank review packet were generated by the
actual RC2 CLI; the annotated packet contains explicitly synthetic assessments.

example, and an allowed prompt-injection observation with one illustrative excerpt.

  --bundle-dir ./synthetic-v2-brief

  --review-file docs/examples/signal-v2/agent-assessment.md \
