# airs-runtime-core

[![crates.io](https://img.shields.io/crates/v/airs-runtime-core.svg)](https://crates.io/crates/airs-runtime-core)

The code shared by the `airs` CLI and the `airs-mcp` service: tenant credentials, SDK clients with URL checks, privacy and secret withholding, Signal Brief evidence and rendering, and the MCP tool schemas.

Built for those two programs. Its version moves in lockstep with them, and its API may change between releases.

Part of [airs-cli](https://github.com/cdot65/prisma-airs-cli). Documentation: <https://cdot65.github.io/prisma-airs-cli/>.
